# 在 OnePaw 中使用 onepaw-ppt

这份说明面向在 OnePaw 里安装、演示 onepaw-ppt 的同事。整个过程不需要安装 Node.js、Python 包或任何其他软件。

## 安装

1. 拿到安装包 `onepaw-ppt-<版本>.zip`：从本仓库的 [Releases](https://github.com/hezhaoqian1/onepaw-ppt/releases) 下载；也可以自己打包，运行 `python tools/build_onepaw_zip.py`，生成的文件在 `dist/` 里（打包这一步需要 Node.js 18+，使用时不需要）。
2. OnePaw → 技能池 → 上传 zip。
3. 把 `onepaw-ppt` 添加到要用的智能体。建议单独建一个做 PPT 的智能体：OnePaw 自带的 `pptx` 技能也能做 PPT，两个放在一起时，智能体可能选错。
4. 给这个智能体配好大模型。实测 DeepSeek `deepseek-flash` 可以正常完成。

**更新到新版本：** 在技能池删除旧的 `onepaw-ppt`，上传新 zip，再到智能体里重新添加，选覆盖。

## 环境检查

装好后对智能体说：

```text
运行 onepaw-ppt 的环境检查
```

它会运行 `scripts/doctor.py`，十几秒后给出结论。最后一行是 `Result: ready` 就可以放心使用。各项检查的含义：

| 检查项 | 说明 | 不通过时 |
|---|---|---|
| Python、PyYAML、技能文件 | OnePaw 和 zip 都自带 | 重新上传 zip |
| Node runtime | 导出 PPTX 用；没装 Node.js 时自动借用 OnePaw 自带的运行环境 | 无法导出 PPTX |
| Browser | 生成预览图做排版质检，用 Chrome 或 Edge（Windows 10/11 自带 Edge） | 跳过图片质检，PPTX 照常导出 |
| Fonts | 微软雅黑，Windows 自带 | 中文字体会被替换 |
| Icons | 图标导出时从网上下载 | 断网时图标显示为圆点 |

## 演示话术

深色、视觉冲击强：

```text
使用 onepaw-ppt 帮我做一个以「企业 Agent 落地」为主题的 PPT，6 页左右，面向企业管理层。风格：深色科技商务风，视觉要丰富、有设计感：多用流程图、架构图、时间轴、数据卡片等图示，少用纯文字和表格。项目放在新文件夹 demo_ppt 里。内容按你的判断来，直接开始做，不用再跟我确认。
```

浅色、正式：

```text
使用 onepaw-ppt 帮我做一个以「企业 Agent 落地」为主题的 PPT，6 页左右，面向企业管理层，讲清楚企业 Agent 是什么、能做什么、典型场景、落地路径和风险控制。风格：浅色、简洁的商务风。项目放在新文件夹 demo_ppt 里。内容按你的判断来，直接开始做，不用再跟我确认。
```

- **使用 onepaw-ppt**：点名技能，避免智能体用别的技能。
- **页数**：用 `deepseek-flash` 做 6～7 页大约 4～6 分钟。现场演示建议 5～6 页。
- **新文件夹**：每次换个名字，免得覆盖上一次的结果。
- **直接开始做，不用再跟我确认**：不加这句，它可能先建议页数，等你确认。
- **想展示它会提问**：改成"先问我想要什么风格和页数，确认后再做"。
- **指定内置主题**：比如"主题用 marine-blue-research"，完整列表见 [theme.md](../theme.md)。

做完后它会给出 `.pptx` 的路径，用 PowerPoint 或 WPS 打开即可。项目文件夹里的 `.qa-images/overview.jpg` 是它自己检查排版用的总览图。

## 现场常见情况

- **中途停下，没说做完**：回复"继续"。
- **模型报错**：再发一次"继续"；还不行就换备用模型。建议提前彩排一次，把成品留作备份。
- **zip 上传被拦截**：OnePaw 的安全扫描会把编辑器自带的网页代码误报为高危。把扫描模式改成"警告"，或把这个技能加入白名单。
- **想手动改**：让智能体"打开 PPT 编辑器"。它会运行 `scripts/serve.py --open`，在浏览器里打开本地编辑器。

## 已知限制

- 图标需要联网下载，断网时显示为圆点，导出结果里会有提示。
- 热力图、桑基图、矩形树图、旭日图这几种特殊图表，以及数学公式，在 PPTX 里可能缺失。常规的柱状图、折线图、饼图不受影响。
- 只在 Windows 上测试过，Mac 未测试。
